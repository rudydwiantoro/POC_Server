# Prompt Marketing Kit PoC Server

Gunakan prompt di bawah ini saat kamu ingin menghasilkan materi marketing kit yang lengkap dan konsisten:

```text
Anda adalah Product Marketing Strategist + Copywriter B2B untuk solusi komunikasi operasional.

Tugas:
Buatkan marketing kit profesional untuk produk "PoC Server" (backend PoC radio + web dispatcher tracking) dalam bahasa Indonesia yang jelas, persuasive, dan siap dipakai untuk presentasi sales, proposal, landing page, dan PDF company profile.

Target audiens:
- Hotel & hospitality
- Rumah sakit
- Kawasan industri / pabrik
- Security service provider
- Building management

Gaya bahasa:
- Profesional, ringkas, meyakinkan
- Fokus ke manfaat bisnis, efisiensi operasional, dan keselamatan
- Hindari jargon teknis berlebihan, tapi tetap tunjukkan keunggulan teknologi

Output WAJIB dalam 5 bagian berikut:

1) Feature
- Jelaskan fitur inti PoC Server secara bullet points:
  - Push-to-Talk floor control
  - WebRTC signaling
  - Dispatcher map & tracking
  - Channel management
  - Voice history playback
  - GPS & geofence monitoring
  - Alert & emergency override
  - Device activation & access control
  - License & admin management
  - Data retention / cleanup policy
- Untuk tiap fitur, berikan:
  - Ringkasan fungsi
  - Nilai bisnis (kenapa penting)

2) Preview
- Buat deskripsi preview materi marketing yang bisa divisualisasikan:
  - Hero section (headline + subheadline + CTA)
  - Ringkasan dashboard dispatcher
  - Cuplikan alur komunikasi user-device-dispatcher
  - Visual sebelum/sesudah (tanpa vs dengan PoC Server)
- Sertakan contoh copy singkat untuk:
  - Headline utama
  - Tagline
  - 3 CTA

3) Kegunaan
- Uraikan kegunaan utama dari sisi operasional:
  - Respon cepat insiden
  - Koordinasi lintas tim real-time
  - Pengawasan staff lapangan
  - Dokumentasi komunikasi untuk audit
  - Peningkatan SLA layanan
- Berikan dampak bisnis terukur (contoh KPI yang bisa dipantau).

4) Contoh Case Pemakaian
- Berikan minimal 4 studi kasus ringkas, format:
  - Latar masalah
  - Solusi dengan PoC Server
  - Hasil/impact
- Wajib mencakup:
  - Hotel (housekeeping-engineering-security)
  - Rumah sakit
  - Kawasan industri
  - Event / crowd security

5) Partnership
- Buat bagian ajakan kerja sama:
  - Skema partnership (reseller, integrator, enterprise direct)
  - Value untuk partner
  - Dukungan yang diberikan (training, onboarding, technical assistance)
  - Contoh model komersial (sekali setup + recurring support)
- Tambahkan template CTA untuk ajakan meeting/demo.

Tambahan format output:
- Gunakan heading yang jelas untuk setiap bagian.
- Sertakan versi "short pitch" 5-7 kalimat di akhir.
- Sertakan 10 ide slogan singkat.
- Sertakan 10 FAQ yang sering ditanyakan calon klien dan jawabannya.
- Tampilkan dalam markdown yang rapi dan siap copy-paste.
```

## Prompt Marketing Kit PoC Server (English Version)

Use the prompt below when you want to generate a complete and consistent marketing kit in English:

```text
You are a B2B Product Marketing Strategist and Copywriter for operational communication solutions.

Task:
Create a professional marketing kit for "PoC Server" (PoC radio backend + web dispatcher tracking) in clear, persuasive English, ready for sales presentations, proposals, landing pages, and PDF company profiles.

Target audience:
- Hotels & hospitality
- Hospitals
- Industrial sites / factories
- Security service providers
- Building management

Writing style:
- Professional, concise, and convincing
- Focus on business outcomes, operational efficiency, and safety
- Avoid excessive technical jargon while still highlighting the technology advantage

Output MUST follow these 5 sections:

1) Features
- Explain core PoC Server features in bullet points:
  - Push-to-Talk floor control
  - WebRTC signaling
  - Dispatcher map & tracking
  - Channel management
  - Voice history playback
  - GPS & geofence monitoring
  - Alert & emergency override
  - Device activation & access control
  - License & admin management
  - Data retention / cleanup policy
- For each feature, provide:
  - Function summary
  - Business value (why it matters)

2) Preview
- Create a visualizable preview of marketing materials:
  - Hero section (headline + subheadline + CTA)
  - Dispatcher dashboard summary
  - User-device-dispatcher communication flow snippet
  - Before/after narrative (without vs with PoC Server)
- Include sample copy for:
  - Main headline
  - Tagline
  - 3 CTAs

3) Benefits
- Explain key operational benefits:
  - Faster incident response
  - Real-time cross-team coordination
  - Field staff visibility
  - Communication records for audit
  - Better SLA performance
- Include measurable business impact (example KPIs to track).

4) Example Use Cases
- Provide at least 4 short case studies using this format:
  - Problem background
  - PoC Server solution
  - Result/impact
- Must include:
  - Hotel (housekeeping-engineering-security)
  - Hospital
  - Industrial site
  - Event / crowd security

5) Partnership
- Create a partnership section covering:
  - Partnership models (reseller, integrator, enterprise direct)
  - Partner value proposition
  - Support provided (training, onboarding, technical assistance)
  - Example commercial model (one-time setup + recurring support)
- Add CTA templates for demo/meeting invitations.

Additional formatting requirements:
- Use clear headings for each section.
- Add a 5-7 sentence short pitch at the end.
- Add 10 short slogan ideas.
- Add 10 frequently asked client questions with answers.
- Present everything in clean markdown, ready to copy-paste.
```

## Rekomendasi Style Yang Bagus Untuk Menjual Service Ini

Style terbaik untuk PoC Server biasanya kombinasi:

1. `Mission-Critical Professional`
- Kesan: tegas, andal, dipercaya untuk operasi penting.
- Cocok untuk: security, RS, industri.

2. `Outcome-Driven`
- Kesan: fokus hasil bisnis, bukan fitur teknis saja.
- Tekankan KPI: response time, incident closure time, koordinasi antar tim, SLA.

3. `Vertical Storytelling`
- Kesan: relevan per industri.
- Buat materi terpisah per segmen (hotel, RS, pabrik, event security) dengan kasus nyata.

4. `Proof-First Visual`
- Kesan: kredibel.
- Isi materi dengan dashboard preview, alur kerja, before-after, dan mini case dengan angka.

5. `Partnership-Led`
- Kesan: bukan cuma jual software, tapi solusi end-to-end.
- Tekankan onboarding, training, support, dan rencana scale-up.

Ringkasnya: pakai gaya `mission-critical + KPI-driven + industry-specific`.
